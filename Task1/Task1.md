
#### Сравнение LLM-моделей

| Модели | Преимущества | Ограничения |
|-|-|-|
| Локальные (hugging face) | - Полный контроль над данными</br> - "Дешёвый" API </br> - Конфиденциальность | - Нужно много мощного "железа" </br> Огрехи в результатах - такие модели менее точны </br> Придётся все настраивать с 0 |
| Облачные | - Стабильно высокое качество генерируемых ответов </br> Быстрое формирование ответа </br> Интеграция "из коробки" | Платный API и ограничения в количестве запросов за день |
